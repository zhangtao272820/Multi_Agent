# 星河科技人事制度（GraphRAG 冒烟样例）

> 用途：便于验证制度图种子 overlap / 条款互引；非生产制度。

## 组织与职责

第1条 【人力资源部】人力资源部是招聘、入职、劳动合同与人事档案的归口管理部门。办公地点：总部 A 座 3 楼。

第2条 【行政办公室】行政办公室负责办公用品、门禁卡制卡与员工工位分配，不负责劳动合同签署。

第3条 【岗位：HRBP】HRBP 岗位隶属于人力资源部，负责跟进入职流程各节点材料齐套情况，并向用人部门同步进度。

第4条 【岗位：招聘专员】招聘专员岗位隶属于人力资源部，负责 Offer 发放前的背调发起；不负责门禁卡办理。

第5条 【岗位：行政专员】行政专员岗位隶属于行政办公室，负责入职当日门禁卡与工位钥匙发放。

## 入职流程

第6条 【流程名称：新员工入职流程】新员工入职流程由人力资源部归口管理。完整办理须在入职日当日 17:00 前完成。

第7条 新员工入职流程必须由 HRBP 主导跟进；招聘专员仅在入职日前完成背调结果回传；行政专员仅在入职当日办理门禁与工位。

第8条 【步骤：材料审核】新员工须提交身份证原件、最高学历证明原件、离职证明复印件。材料审核由 HRBP 在入职日前 1 个工作日完成初审。

第9条 【步骤：劳动合同签署】材料审核通过后，由人力资源部指定经办人与员工签署劳动合同；行政办公室不得代签。

第10条 【步骤：门禁与工位】劳动合同签署完成后，行政专员凭人资开具的《入职完成单》发放门禁卡与工位钥匙。无《入职完成单》不得制卡。

第11条 第10条门禁发放以第9条劳动合同签署完成为前置条件；第9条又以第8条材料审核通过为前提。

## 请假与审批

第12条 【流程名称：事假审批流程】事假审批流程由行政办公室归口管理，用于 1 个工作日及以上的事假申请。

第13条 事假审批流程要求直线经理初审，行政专员备案；连续请假超过 3 个工作日的，须追加人力资源部 HRBP 会签。

第14条 【步骤：提交申请】员工在 OA「假勤」模块提交事假申请，写明事由与起止日期。

第15条 【步骤：直线经理审批】直线经理须在 1 个工作日内完成同意或驳回；驳回须填写原因。

第16条 【步骤：行政备案】审批通过后，行政专员在假勤台账登记；超过 3 日的须同步抄送 HRBP。

第17条 事假审批流程与新员工入职流程相互独立：试用期员工亦可按本章申请事假，但不免除入职材料补交义务（参见第8条）。
