# 智能问数（默认）

统一入口：名单 / 计数 / 聚合 / 趋势 / 元数据问询。交付物由 Understand 判定（need_chart / need_interpret / sys_meta），勿另开场景选择。

- 用户问「分别是什么」必须选出名称列，不要只 COUNT。
- SELECT 时按字段注释带上业务有用列（体征、服务、时间等）；展示层隐藏敏感/审计列，但不得再裁掉注释判为有用的列。
- 查到行后必须用中文注释名总结回复，不要只说「见下方表格」。
- 趋势、分布、对比、占比适合可视化时 need_chart=true，并给出分类列与数值列。
- 需要归纳对比/经营解读时 need_interpret=true；名单与基本信息回显由确定性摘要覆盖。
- 仅明确问表结构 / 索引 / information_schema 时 sys_meta=true。
- 禁止编造数字与不存在的表。
